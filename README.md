## The image

A colossal ocean wave at golden hour, its towering crest ignited into
burning gold and orange fire, curling into a perfect barrel. Inside the
barrel, a lone surfer silhouetted in black rides the wave, tiny against
the immense wall of water. Deep teal and dark blue ocean against the
blazing crest; spray exploding from the lip into glowing embers; the
setting sun shining through the barrel's mouth.

One subject, one moment, one impossible scale: a human the size of a
spark inside a wave the size of a mountain — and the wave is on fire.
It is built to be felt in the first half-second of looking, the way the
judge sees it: two images side by side, one winner.

## Run it

Node.js 22 or later, standard library only, nothing to install:

```sh
node main.ts
```

`main.ts` copies the fixed asset `assets/entry.png` byte-for-byte to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set).
No network, no clock, no randomness — two runs write identical bytes.

The image is a whole PNG, 1024x1024 pixels, 635,782 bytes (under the
1 MiB gate). The asset was generated once during the build and
compressed to fit the gate (see `BUILD_LOG.md`, kept out of this repo
as a work file); the program itself only copies it.
